# Contributing

## Workflow

In general, we follow the "branch-and-pull" [GitHub-Flow](https://docs.github.com/en/get-started/quickstart/github-flow) workflow.

1. Clone the project to your own machine
2. Commit changes to a branch. Limit the scope of the changes to a single issue or feature.
3. Push your changes to the remote repository.
4. Create a pull request and request a review from a team member.
5. Address any requested changes from the reviewer and re-request a review until the reviewer approves the pull request.
6. Merge the pull request.
7. Delete your branch.
